# Progress reports

This directory contains dated thesis progress reports. Each folder keeps the
LaTeX source, its local figure assets, and the PDF compiled from that source.
Temporary LaTeX build files are not tracked.

Report folders retain finished documents, figures, tables, numerical snapshots
and historical audit/provenance records. Some one-off generation or publication
helpers were removed after report preparation; historical manifests may still
name them. Start with the PDF to read the report, or its folder notes for build,
source, and experiment links.
