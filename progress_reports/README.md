# Progress reports

This directory contains dated thesis progress reports. Each folder keeps the
LaTeX source, its local figure assets, and the PDF compiled from that source.
Temporary LaTeX build files are not tracked.

Report folders retain finished documents, figures, tables, numerical snapshots
and historical audit/provenance records. One-off Python generation, formatting
and publication helpers have been removed after report preparation. The supplied
LaTeX and assets can still be compiled directly; no Python preparation is needed.
Historical manifests may name removed helpers: those entries describe the
original publication, not a current executable-file inventory. Experiment and
training implementations remain in their own project directories.
